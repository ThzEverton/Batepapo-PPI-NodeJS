# Bate-Papo PPI — Node.js

Aplicação web acadêmica para estudo de sessões, cookies, autenticação e troca de mensagens.

## Funcionalidades

- Login
- Cadastro de usuários
- Sessão autenticada
- Cookie de última visita
- Sala de bate-papo
- Histórico de mensagens em memória
- Rotas protegidas
- Interface HTML gerada pela aplicação

## Stack

- Node.js
- Express
- express-session
- cookie-parser
- JavaScript ES Modules

## Executando localmente

```bash
npm install
npm start
```

A aplicação inicia na porta `3000`.

## Contexto

Projeto acadêmico voltado ao aprendizado de HTTP, middleware, cookies e sessões. A persistência e as credenciais de demonstração são simplificadas e não devem ser utilizadas como referência de segurança para produção.
